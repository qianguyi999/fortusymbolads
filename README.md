# Fortusymbol Static Website

Static HTML website for `fortusymbolads.com`.

## Pages

- `index.html`
- `advertising.html`
- `online-advertising.html`
- `business-info.html`
- `exhibitions.html`
- `procurement.html`
- `import-export.html`

## Cloudflare Pages Settings

- Framework preset: None
- Build command: leave empty
- Build output directory: `/`
- Production branch: `main`

## Update Flow

1. Edit the HTML files.
2. Commit and push changes to GitHub.
3. Cloudflare Pages deploys the new version automatically.
4. If an update has a problem, roll back from the Cloudflare Pages deployment history.
